# 洛克观测站 · S5 龙棋士反推

**ROCO OBSERVATORY** — 面向洛克玩家的离线战斗观测、生命/物攻/魔攻性格提升项辅助判断与测算记录工具。

**物防、速度仅在表情指示时判定；暂不支持物防、魔防和速度的战斗反推，后续可能上线，暂无确定时间。** 战斗记录仅辅助判断生命、物攻、魔攻的性格提升项。物防、速度仅在开心、困倦、怯懦或暴怒的对应表情指示时显示，并注明“表情得出”；开心只能确定物防或速度二选一。平和、未看清时隐藏这两项，不用战斗记录消除其表情歧义。相关双防、速度战斗公式尚未完成校准，不能据此推断数值或天分；六维资料、已知面板、捕后数据与旧版快照仅供记录或对照。

本项目为非官方玩家研究工具，与游戏官方及其他同类应用无隶属关系。

## 下载和使用

1. 下载 [洛克观测站-S5龙棋士反推.html](./洛克观测站-S5龙棋士反推.html)。在 GitHub 文件页面选择下载原始文件；直接浏览仓库文件页面不会运行应用。
2. 使用现代浏览器打开下载的 HTML，无需安装 Node.js 或启动服务器。
3. 点击导航栏「使用说明」，按快速上手步骤创建精灵档案、配置目标并添加观测，再判断加成。
4. 定期导出精灵池和测算记录 JSON 备份。

## 提供的功能

- 根据表情、物理/魔法受击和状态扣血记录，辅助判断生命、物攻、魔攻的性格提升项。
- 物防和速度仅在对应表情指示时显示，并注明“表情得出”：困倦为物防提升，怯懦/暴怒为速度提升；开心保留物防或速度二选一。平和/未看清时隐藏，不使用战斗记录判断这两项。
- 保存个人精灵池、战斗观测、测算结果及捕后对照。
- 查阅计算所需的精灵数值、技能计算摘要和骰面参数。
- 在「使用说明」中查看操作步骤、计算规则、校验范围、来源核对及许可说明。
- 导出/导入 JSON 备份、导出观测 CSV，以及导出含个人精灵池的分享网页；测算 JSON、CSV 和分享网页保留当前支持范围说明。

## 数据保存

个人精灵池、测算记录和草稿保存在当前浏览器的本地存储中；发布文件的初始精灵池为空，不包含发布者保存的个人档案。

更换浏览器、网页地址或本地文件路径时，请先导出 JSON，再在新位置导入。清除浏览器数据可能删除本地记录。分享网页会包含你主动导出的精灵池，请在发送前确认内容。

## 模型局限

**物防、速度仅在表情指示时判定；暂不支持物防、魔防和速度的战斗反推，后续可能上线，暂无确定时间。** 物防、魔防、速度的战斗反推公式尚未完成校准；我方已知双防用于受击试算，六维面板正算、捕后对照及历史快照不能当作这三项的反推结论。“判别成功”仅指当前支持范围内的性格提升项；物防、速度的结论只由表情得出，不表示战斗反推已开放。

龙龙骰效果来源不一定可靠，请核对游戏内实际数据后再测算。「全能」预设已更正为全属性＋30%，生命倍率1.3。旧记录中的50%参数保留原始快照；需要按30%重新测算时，请重新选择「全能」并复核受影响的观测。

当前部分伤害、属性和生命换算仍是基于有限样本的候选模型，并非官方机制。已参与拟合的样本不等于独立盲测；未校准的等级、星级、外观或技能条件可能产生不准确结果。请结合「使用说明 → 计算规则与校验」中的适用范围核对。
