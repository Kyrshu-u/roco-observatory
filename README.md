# 洛克观测站 · S5 龙棋士反推

**ROCO OBSERVATORY** — 面向洛克玩家的离线战斗观测、生命/物攻/魔攻性格提升项辅助判断与测算记录工具。

**物防、速度仅在表情指示时判定；暂不支持物防、魔防和速度的战斗反推，后续可能上线，暂无确定时间。** 战斗记录仅辅助判断生命、物攻、魔攻的性格提升项。物防、速度仅在开心、困倦、怯懦或暴怒的对应表情指示时显示，并注明“表情得出”；开心只能确定物防或速度二选一。平和、未看清时隐藏这两项，不用战斗记录消除其表情歧义。相关双防、速度战斗公式尚未完成校准，不能据此推断数值或天分；六维资料、已知面板、捕后数据与旧版快照仅供记录或对照。

本项目为非官方玩家研究工具，与游戏官方及其他同类应用无隶属关系。

## 下载和使用

1. 在 [v0.1.1 发布页](https://github.com/Kyrshu-u/roco-observatory/releases/tag/v0.1.1) 下载 Assets 中的 HTML，或下载仓库中的 [洛克观测站-S5龙棋士反推.html](./洛克观测站-S5龙棋士反推.html)。在 GitHub 文件页面选择下载原始文件；直接浏览仓库文件页面不会运行应用。
2. 使用现代浏览器打开下载的 HTML，无需安装 Node.js 或启动服务器。
3. 点击导航栏「使用说明」，按快速上手步骤配置目标并添加观测。受击观测先建立我方精灵档案；破盾后的回血观测无需我方档案。
4. 定期导出精灵池和测算记录 JSON 备份。导入时将文件拖入弹窗，或点击「选择文件」；文件仅在本机读取。

## 提供的功能

- 根据表情、物理/魔法受击和状态扣血记录，辅助判断生命、物攻、魔攻的性格提升项。
- 选择「破盾后本体」时，仅通过百分比回血与完整回血飘字测算本体生命范围；支持回血技能、骰面回复、自填比例、通常/应对分支及取整方式。
- 仅选择对应表情即可查看、保存或导出判定，无需填写等级、外观、我方精灵或战斗信息。
- 物防和速度仅在对应表情指示时显示，并注明“表情得出”：困倦为物防提升，怯懦/暴怒为速度提升；开心保留物防或速度二选一。平和/未看清时隐藏，不使用战斗记录判断这两项。
- 保存个人精灵池、战斗观测、测算结果及捕后对照。
- 查阅计算所需的精灵数值、技能计算摘要和骰面参数。
- 在「使用说明」中查看操作步骤、计算规则、校验范围、来源核对及许可说明。
- 导出/导入 JSON 备份、导出观测 CSV，以及导出含个人精灵池的分享网页；测算 JSON、CSV 和分享网页保留当前支持范围说明。

## 数据保存

个人精灵池和手动保存的测算记录保存在当前浏览器的本地存储中；未保存的输入只在当前页面暂存，刷新或关闭后会丢失。发布文件的初始精灵池为空，不包含发布者保存的个人档案。

更换浏览器、网页地址或本地文件路径时，请先导出 JSON，再在新位置导入。清除浏览器数据可能删除本地记录。分享网页会包含你主动导出的精灵池，请在发送前确认内容。

## 模型局限

**物防、速度仅在表情指示时判定；暂不支持物防、魔防和速度的战斗反推，后续可能上线，暂无确定时间。** 物防、魔防、速度的战斗反推公式尚未完成校准；我方已知双防用于受击试算，六维面板正算、捕后对照及历史快照不能当作这三项的反推结论。“判别成功”仅指当前支持范围内的性格提升项；物防、速度的结论只由表情得出，不表示战斗反推已开放。

龙龙骰效果来源不一定可靠，请核对游戏内实际数据后再测算。「全能」预设已更正为全属性＋30%，生命倍率1.3。旧记录中的50%参数保留原始快照；需要按30%重新测算时，请重新选择「全能」并复核受影响的观测。

当前部分伤害、属性和生命换算仍是基于有限样本的候选模型，并非官方机制。已参与拟合的样本不等于独立盲测；未校准的等级、星级、外观或技能条件可能产生不准确结果。请结合「使用说明 → 计算规则与校验」中的适用范围核对。

破盾后的回血观测仅反解当时本体生命范围，不将护盾生命模型套到本体，也不据此判断生命性格加成。回复比例必须对应最大生命且未被回满截断；实际存在额外回复修正时，须先核对并填写正确比例。

## 连击录入、异色样本与可能搭配

更新日期：2026-11-09。v0.1.1将先前独立预览中的连击提示、异色样本说明及多解展示纳入发布HTML；保留现有候选公式，后续校准进展以GitHub版本更新为准。

### 连击攻击只需输入一段伤害

连击攻击仅需输入其中一段（一层）的完整整数飘字，包含溢出伤害，不填各段相加的总伤害。相同条件、相同数值的一段记录即可；不同段的基础威力、增减益或飘字不同时，分别补录对应条件。

例如同一招连续显示40、40、40，只需录入一条40，不能填写120。若下一段因增益变化显示50，应按那一段的实际条件另录50。

增加连击次数不会作为当前单段伤害公式的倍率。本次无需新增参与计算的“额外连击数”字段；连击＋1、额外释放等次数可写入备注，便于复核，不加入伤害修正或最终倍率。应对只增加段数时也按这一规则记录。

“计算修正”仍需区分技能威力、攻防变化与独立伤害倍率。例如开心攻击＋50%与魔攻＋100%按同类攻击变化合并为＋150%时，攻防修正为2.5；没有其他独立伤害效果时，最终倍率为1。不能再把这次攻击＋50%填成最终×1.5。

### 异色数据仍少，暂时保留现有公式

当前异色数据较少，破盾后外观与护盾战斗攻击模板之间的对应仍待校准。部分记录在选择破盾后非异色时，需约1.2倍攻击模板才能复现；另一些记录又符合1倍模板。因此，本次暂不修改公式，也不统一给非异色追加1.2倍。

当前仍沿用的工作候选为：`A战=round((2A₀+22)×M)`，非异色模板M=1、异色模板M=1.2；A₀取同等级0星、零攻击天分且保留性格的参考值。模板名称代表计算假设，数值吻合不能反过来证明实际外观。

深蓝鲸在当前候选中存在以下重合：

| 等级 | 异色攻击模板＋魔攻降低 | 非异色攻击模板＋魔攻提升 |
|---|---:|---:|
| 41级 | 战斗魔攻286 | 战斗魔攻286 |
| 42级 | 战斗魔攻288 | 战斗魔攻288 |
| 43级 | 战斗魔攻293 | 战斗魔攻292 |

这些是战斗攻击候选，不能当作捕捉后实际面板。其他条件相同时，41、42级的两种搭配无法仅靠魔法伤害区分；43级虽差1点，最终伤害也可能因取整相同。

- 异色攻击模板＋魔攻降低。
